## Text Elements
Processo de Carga de Dados ^u2klHx82

Executar a ferramenta Create Simple Data Mapping ^O6aFC31z

Preencher a planilha gerada DataMapping.xlsx  ^CDNIo6a9

Executar a ferramenta Create Migration Workspace ^3P9WaMka

Neste passo, mapeamos as entidades da base original com classes, grupos e tipos na Utility Network. Podemos também criar novos grupos e tipos de forma automática. ^4GDfMvCD

Neste passo, mapeamos os campos das entidades na Utility Network. O uso do dicionário de dados da Utility Network pode facilitar o processo, bem como o dicionário de dados da própria base a ser migrada. ^KTXzHfyk

Preencher as planilhas  DataReference.xlsx ^6vLfoJ0e

Executar a ferramenta
 Load Data Using Workspace ^gqqPR16j

Neste passo, realizamos a carga dos dados na Utility Network. Caso seja uma situação de testes, podemos utilizar a ferramenta Load Data To Preview para carregar os dados em um geodatabase temporário. ^i0LQhO5S

Executar a ferramenta
 Asset Package to Geodatabase ^vnUWEIaY

Neste passo, implantaremos de fato a Utility Network, mediante o tipo de  geodatabase empregado. ^lJ3cjmsM

Enterprise Geodatbase? ^aU2y6S0k

Executar Stage Utility Network e Apply Asset Package ^lx42ZYxM

Não ^ysFBCZtI

Sim ^qILibtkQ

Executar a ferramenta Enable Network Topology ^jFUp9mbr

Executar Summarize Utility Network Errors ^O5CJYg2k

Neste passo, habilitamos a topologia da rede e buscamos por erros na Utility Network. ^6uiCIlsT

Executar a ferramenta Update Data Sources ^RUAQfoI6

Neste passo, a partir do projeto base (Essentials ou Expanded) atualizamos as fontes de dados dos mapas. ^fu1ZEVR1

Executar a ferramenta Change Asset Package Spatial Reference e instalar untools e utilsolutions antes de começar!  ^k3aIC8a4
